## 검증과 남은 작업

전투 시뮬레이션 회귀 테스트로 토템 효과, 상태 전이, 중복 획득, 선택형 도전, 로그 연결, 3장 보스 패턴을 검증합니다. 실제 사람의 입력 체감·가독성·이해도 검증과 모집 플레이테스트는 아직 수행하지 않았습니다. 수치는 1차 조정안이며 통계적으로 밸런스가 검증된 결과가 아닙니다. 3장 전용 아트·사운드, 전체 로그 통합 분석 대시보드, 장기 세이브는 후속 작업입니다.

## 안정화 기록

- 2장 바로 시작은 정상 승격과 같은 기본 보너스(최대 체력 +20, 공격력 +6, 수익 50)를 적용합니다. 1장에서 획득한 종목·토템까지 복제하지는 않습니다.
- 직접 공격 약화는 전달된 공격자 객체에 적용하며 좌표가 같은 다른 적에게 전파되지 않습니다. 피해 로그에 source_id와 damage_kind를 추가했습니다. 적 투사체·보스 위험지대에는 생성 당시 공격자 ID를 보존합니다. 환경 경보는 source_id가 null이며 source_type은 environment입니다.
- 레버리지 상환은 실제 차감량을 health_cost / leverage_repayment로 기록합니다. 전투 피해 통계에는 포함하지 않습니다.
- 다음 검증: 브라우저에서 1·2장 입력·선택창·재시작 연속 점검, 실제 플레이 로그를 통한 기존 5종 밸런싱. 이번 안정화는 자동 테스트로 검증했으며 브라우저 플레이 완료를 의미하지 않습니다.

- 후속 안정화: 접촉·폭발·투사체·보스 바닥 공격의 출처 연결, 폭탄 자폭 처치 이벤트와 중복 방지. 자동 테스트 43개 통과. 브라우저 플레이 검증은 여전히 남아 있습니다.

## 여러 플레이 로그 분석

게임에서 내려받은 파일을 모아 실행합니다(Node.js 필요).

```sh
node scripts/analyze-runs.mjs session1.json session2.json > analysis.json
```

단일 도전 로그와 여러 도전이 담긴 runs 파일 모두 지원합니다. run_id + sequence로 중복을 제거하고 충돌한 이벤트는 오류로 표시합니다. 순서가 누락된 로그는 제외하며, 종료하지 않은 도전은 unresolved로 구분합니다. 토템 제시는 도전·방·토템마다 한 번만 세며 선택률 분모는 실제 제시 횟수입니다.

결과: 방별 시작·완료·사망·완료 전 종료·미종료 수, 완료율, 사망률, 완료한 방의 평균 시간, 토템별 제시·선택·발동 횟수와 형성 실패 사유. 상점은 kind=shop으로 분리합니다. 이는 수집한 도전들의 기술 통계이며 전체 사용자 이탈률이나 토템의 인과적 효과를 의미하지 않습니다.

개발 기록: 로그 병합·중복 제시·미종료·불완전 기록·충돌 검증을 추가해 전체 46개 테스트 통과. 다음 작업은 실제 내보낸 로그를 이 분석기에 적용하고 표본을 바탕으로 형성 시간과 보상을 조정하는 것입니다.

## 4장 중앙은행

국채 광장 → 긴축 회랑 → 최종 대부 창구 → 지급준비 금고 → 통화정책 위원회.
3장 출구에서 최대 체력 +20·공격력 +6·체력 45 회복·수익 50을 받고 진입합니다. 기존 종목과 토템은 유지됩니다. 1·2·4번 방에 탐험 상자·숨겨진 보관함·선택형 엘리트 도전을 연결했습니다.

중앙은행 총재: 금리 인상(순차 바닥 폭발), 유동성 공급(느린 부채꼴 탄막), 지급준비율 인상(중앙에 안전 구역을 남기는 바닥 공격). 공격 전 안내와 예고선을 제공하며 체력 절반 아래에서 회복 틈이 짧아집니다. 금융 개념을 게임용으로 각색한 패턴입니다.

4장 배경은 기관 배경에 황금색 필터를 적용합니다. 몹은 새 중앙은행 전용 스프라이트를 사용합니다. 전용 음악은 아직 없습니다. 기존 보상 풀과 상점이 연결됩니다. 개발 기록: 3→4장 전환·토템 유지·정책 3종·최종 승격·종료 로그 검증 포함 47개 테스트 통과.

## Tiny 전투와 지형 확장

캐릭터와 몬스터의 월드 렌더 크기 및 몸체 판정을 기존의 70%로 축소했습니다. 원본 이미지는 보존합니다. 이동·점프 성능과 공격 범위는 유지합니다. 일반 전투/엘리트방마다 1장은 2마리, 이후 장은 3마리 추가 배치했습니다.

개발 기록: 기존 디자인 유지, Tiny 크기 적용, 적 밀도 및 지형 확장. 벽 대시 차단·착지, 지뢰 예고·일시정지·단발성, 방별 생성 회귀 테스트 포함 51개 통과.

## 이동·공중 전투 개선 (2~4단계)

- C를 놓는 시점으로 점프 높이 조절. 이단 점프와 입력 버퍼 유지.
- ↑+X 위 공격, 공중 ↓+X 아래 공격. ↓+C는 발판 내려가기.
- 아래 공격 적중 시 반동, 공중 점프 1회와 대시 재사용 기회 제공. 빗나가면 반동 없음.
- 기본 공격은 35ms 준비 후 한 번 타격하고 회수. 대시·피격으로 준비 동작 취소 가능.
- 기존 Tiny 스프라이트를 활용한 자세 변형과 방향성 무기 표현, 타격 궤적·착지 먼지 추가. 신규 스프라이트 시트는 사용하지 않음.
- 기본 1·2타 이동속도 95%, 3타 85%로 조정(기존 65%).
- 공격 로그에 방향·공중 여부, 반동 성공에 pogo_success 기록.
- 검증: 기존 회귀와 점프 높이·방향 판정·반동·공격 취소·일시정지 포함 58개 테스트 통과.

## 벽 이동·세로 카메라 (5단계)

- 물리 벽을 향해 방향키를 유지하면 낙하 속도가 초당 120으로 제한됩니다. 손을 떼면 일반 낙하로 돌아갑니다.
- 벽 접촉 중 C로 반대 방향으로 도약합니다. 0.16초 동안 반대 입력에 즉시 상쇄되지 않으며, 공중 점프 1회를 남깁니다.
- 배경 장식과 얇은 발판에는 벽 점프가 적용되지 않습니다. 접촉 가능한 벽 양쪽에 밝은 테두리와 반복 표식을 추가했습니다.
- 세로 카메라는 중앙 완충 구간과 속도 기반 앞보기로 상승·낙하를 추적합니다. HUD는 고정합니다.
- 전투방의 상단 이동 한계를 -360까지 확장했습니다. 상점·보스방은 기존 상단 한계를 유지합니다. 방 전환 시 카메라와 벽 이동 상태를 초기화합니다.
- wall_jump 이벤트를 기록합니다. 회귀 포함 63개 테스트 통과.
- 다음 단계: 손절 교차로의 갈림길·재합류·지름길 재설계. 이번 변경은 이동 기반이며 전체 수직 맵 재설계는 포함하지 않습니다.

## 손절 교차로 탐험 개편 (6~10단계의 기준 구간)

- 1장 두 번째 방에 하층 우회·상층 이동 도전·출구 재합류를 적용했습니다. 하층에는 근접 적 3마리, 상층에는 방패·비행·원거리 적 9마리를 배치합니다.
- 이 방은 전멸 대신 출구에서 ↑를 누르면 탐험 완료 보상을 제시합니다. 선택 후 다시 ↑로 다음 방에 이동합니다. 다른 방의 기존 전투 조건은 유지합니다.
- 상층 숨겨진 상자는 선택형 엘리트 도전입니다. 거절하거나 진행 중 떠날 수 있으며, 완료하면 토템 선택지와 시드 보상을 받습니다.
- 상층 스위치 근처에서 ↑로 연결교를 펼칩니다. 하층에서 상층으로 돌아오는 발판으로 이용할 수 있습니다. 방을 새로 시작하면 초기화합니다.
- 위·아래 경로의 적은 다른 높이의 플레이어에게 한꺼번에 몰리지 않도록 활성 범위를 구분합니다.
- 연결교 개방·레버리지 사용·진행 중 도전 포기에 돌파·레버리지·손절 설명을 연결했습니다. 설명은 게임적 비유이며 실제 가격 방향을 보장하지 않는다고 표시합니다.
- 로그: route_selected(경로별 첫 방문), route_rejoined, shortcut_opened, shortcut_used, elite_trial_abandoned, concept_exposed. 탐험 stage_clear는 completion=traversal 및 남은 적 수를 기록합니다.
- 요약 로그에 탐험 완료·상/하층 방문·지름길·개념 노출 집계를 추가했습니다. 노출 횟수는 학습 이해도의 증거가 아닙니다.
- 자동 검증 68개 통과. 하층 실제 이동 시뮬레이션, 생존 적을 남긴 완료, 보상 1회 지급, 스위치 거리, 도전 포기·완료, 경로 로그 중복 방지를 포함합니다.
- 남은 순서: 기준 구간의 조작·난도 피드백 반영 → 1장 나머지 방 → 2~5장 테마별 확장. 재미·학습 성과 검증과 전체 장 확장은 아직 완료되지 않았습니다.

## 1장 전체 방 확장

- 폐장 골목: 낮은 진입 발판 → 벽 점프 → 공중 공격 연습 → 상층 토템·연결교. 하층 출구에서 ↑로 탐험 보상을 받습니다. 지뢰는 후반 하층에 1개 배치합니다.
- 손절 교차로: 기준 구간 유지. 상층 적 인지 거리를 320, 하층을 380으로 조정해 한꺼번에 접근하는 압박을 줄입니다.
- 공칠의 거래소: 적·함정 없는 5단 연결 발판으로 점프·내려가기 연습. 중앙 상점은 기존 방식으로 이용합니다.
- 폐쇄 거래소: 방패·근접·폭탄·비행 적 12마리를 세 구역에 분산 배치. 전체 본 전투 처치 후 보상, 별도 상층 엘리트 토템 도전은 선택입니다.
- 작전세력 소굴: 보스 돌진을 위한 바닥을 유지하고 5단 공중 회피 발판을 배치했습니다.
- 방마다 이동 안내 표지 추가. 경로·지름길 기록은 방 크기와 배치에 맞춰 집계합니다.
- 검증: 72개 테스트 통과. 첫 방 실제 하층 이동, 캐릭터·적·상자와 벽의 초기 겹침, 상점 안전성, 엘리트·보스 봉쇄, 1장 전체 진행과 방별 완료 1회 기록을 포함합니다.
- 이번 확장은 1장까지입니다. 2~5장은 기존 콘텐츠를 유지하며, 플레이 체감에 관한 피드백과 장별 재설계는 후속 작업입니다.

## 2~5장 탐험 구조 확장

- 각 장 첫 두 방에 하층 우회·상층 토템·연결교 지름길·출구 재합류를 적용했습니다. 출구에서 ↑로 탐험 완료 보상을 받습니다.
- 2장: 기관 주문 데크와 로비 우회로. 방패·드론 중심의 계단형 배치.
- 3장: 알고리즘 전송 회랑과 캐시 우회로. 높이 75까지 올라가는 상승·하강 경로, 드론 중심 배치.
- 4장: 지급준비 상층 금고와 국채 하부 통로. 방패 중심의 상층 경로.
- 5장: 버블 상층 균열과 가격발견 우회로. 높이가 교차하는 발판과 폭탄·비행·방패 조합.
- 일반·엘리트방은 기본 12마리(하층 4, 상층 8). 탐험방은 경로별 활성 범위를 구분하며 엘리트방은 본 전투 전멸 조건을 유지합니다.
- 첫 탐험방은 일반 토템, 두 번째 탐험방은 숨겨진 선택 도전. 기존 엘리트방의 선택 토템 도전도 유지합니다.
- 각 장 상점은 안전한 이동 연습 발판, 보스방은 바닥 돌진 공간과 공중 회피 발판으로 구성했습니다. 기존 보스 패턴·챕터 성장·장별 몬스터 외형을 재사용합니다.
- 검증: 76개 자동 테스트 통과. 추가 탐험방 8개의 실제 하층 이동, 보상 1회 지급, 스위치 중복 방지, 2~5장 모든 방의 초기 적·벽 겹침과 맵 경계, 상점 안전성 및 전투 봉쇄를 포함합니다.
- 공통 구조의 장별 변형이며 새로운 보스 패턴이나 신규 몬스터 그림을 추가한 작업은 아닙니다. 난도와 재미의 최종 평가는 플레이 피드백으로 조정합니다.

## 적 피해 소폭 하향

플레이 피드백에 따라 적이 플레이어에게 주는 피해에 0.9 배율을 적용했습니다. 일반·엘리트·보스의 근접, 접촉, 투사체, 자폭과 보스 바닥 패턴에 한 번만 적용합니다. 정수 반올림으로 실제 감소율은 공격별로 조금 다릅니다. 지뢰·가시·낙하·환경 경보와 레버리지 상환 비용은 유지합니다. 기존 약화 효과도 새 배율과 함께 계산합니다.
