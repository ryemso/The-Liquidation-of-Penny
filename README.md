# The Liquidation of Penny

금융 개념을 전투와 성장으로 구현한 2D 횡스크롤 액션 로그라이트 브라우저 프로토타입.
기준 저장소: https://github.com/ryemso/The-Liquidation-of-Penny

## 현재 플레이 범위

- 1장 잡주의 골목: 폐장 골목 → 손절 교차로 → 공칠의 거래소 → 폐쇄 거래소 → 작전세력 소굴
- 2장 기관의 벽: 증권사 로비 → 기관 주문센터 → 리스크 관리실 → 공매도 구역 → 헤지펀드 본사
- 3장 알고리즘의 심장: 데이터 회랑 → 지연된 주문실 → 캐시 정거장 → 고빈도 매매 구역 → 알고리즘 코어
- 장마다 5개 방, 총 20개 방. 1장 뒤 Small Cap, 2장 뒤 Mid Cap, 3장 뒤 Blue Chip, 4장 완료 시 Mega Cap.
- 3장 아트는 기존 기관 배경·드론을 재사용한 프로토타입입니다. 보스는 예측 사격, 지연 바닥 공격, 전체 바닥 스윕을 사용합니다.
- BGM `Degraded Signal`은 1·2장에서 재생하며 3장 전용 음악은 아직 없습니다.

## 조작과 실행

← → 이동 / C 두 번 점프 / X 기본 3단 공격 / Z 무적 대시 / A 익절 / S 레버리지 / D 서킷브레이커 / ↑ 출구·상점 / I 토템 / Esc 일시정지.

루트에서 `python -m http.server 8000` 실행 후 `http://localhost:8000` 접속.
테스트: `node --test tests/*.test.mjs`.

개념은 제공받은 Yonsei_dent 차트 패턴 가이드(2024-11-17)를 참고했습니다. 전투 조건·수치는 게임용 각색이며, 원문과 도해를 복제하지 않았습니다. 각 토템의 정확한 조작·효과·형성 시간·대기시간은 게임 메뉴와 `totems.mjs`에 표시됩니다. 신규 순서형 토템은 피격 시 형성이 초기화됩니다.

최대 3종을 장착합니다. 선택한 토템과 기존 슬롯의 효과를 나란히 비교할 수 있습니다. 교체 시 형성 진행은 초기화되고 재사용 대기시간은 유지됩니다. HUD는 다음 행동을 안내합니다.

기존 5종의 형성 시간: 이중 바닥·천장·삼각수렴 12초 / 깃발 8초 / 컵앤핸들 10초. 준비한 추가 피해는 이미 사망한 적에게 소모되지 않습니다. 몸체 접촉은 회피 성공으로 집계하지 않으며 대시 무적 .23초 동안 실제 공격을 막아야 합니다. 대시당 최대 한 번 인정됩니다.

## 탐험

각 장 1·2·4번 방의 선택형 상층 경로에서 작은 24×18 상자를 찾습니다. 닿으면 기존 차트 선택 화면이 자동으로 열립니다. 미보유 토템 최대 2종 중 하나를 선택합니다. 전부 보유하면 시드 40을 얻습니다.

- 각 장 2번 방: 180 거리 이내 접근 시 드러나는 숨은 보관함. 250 거리 이내에는 작은 빛이 단서입니다.
- 각 장 4번 방: 강화 드론과의 선택형 도전. 거절 가능하며, 시작 후에도 원래 출구로 떠날 수 있습니다. 격파하면 시드 25와 최대 3종의 보관함 선택지를 얻습니다.
- 선택을 미룬 뒤 상자에서 벗어났다가 다시 닿으면 같은 선택지를 다시 엽니다.
- 보유 토템과 장착은 다음 장까지 유지하며 새 도전에서 초기화됩니다.

## 플레이 분석

`analytics.mjs`가 run_id, stage_id, chapter, 시뮬레이션 시간, 실제 시각, 체력, 시장, 장착 토템을 공통 필드로 기록합니다.

주요 이벤트: run_start, stage_start, stage_clear, stage_exit, enemy_encounter, enemy_defeated, attack, attack_hit, damage_taken, dodge_success, reward_presented, reward_selected, player_death, run_end, secret_found, elite_trial_started/declined/clear 및 토템 발견·제시·선택·장착·형성·실패·발동.

- 상단 ‘플레이 로그’: 현재 도전 및 브라우저에 저장된 최근 5개 도전의 JSON 다운로드.
- 토템 메뉴: 현재 도전 전체 로그 다운로드.
- 한 도전 최대 30,000 이벤트. 초과 시 오래된 기록을 제거하고 truncated=true로 표시합니다.
- 서버로 전송하지 않습니다. 다른 기기의 사용자 데이터는 각자 내보낸 파일을 수집해야 합니다.
- stage_completion_rate는 해당 로그의 stage_clear / stage_start입니다. 상점도 진입 방으로 포함하고 출구로 나갈 때 완료 처리합니다.
- 사망과 중도 종료를 구분합니다. page_exit/restart는 종료 사유이며, 탭 강제 종료·브라우저 충돌 때 기록 누락이 가능합니다. 단순 stage_start 누락을 이탈로 단정하지 마세요.
- reward_presented 및 totem_offer_shown의 제시 목록을 분모로 사용하세요. 재열기로 중복 제시될 수 있으므로 run_id+stage_id로 중복을 처리해야 합니다.

## 검증과 남은 작업

전투 시뮬레이션 회귀 테스트로 토템 효과, 상태 전이, 중복 획득, 선택형 도전, 로그 연결, 3장 보스 패턴을 검증합니다. 실제 사람의 입력 체감·가독성·이해도 검증과 모집 플레이테스트는 아직 수행하지 않았습니다. 수치는 1차 조정안이며 통계적으로 밸런스가 검증된 결과가 아닙니다. 3장 전용 아트·사운드, 전체 로그 통합 분석 대시보드, 장기 세이브는 후속 작업입니다.

## 안정화 기록

- 2장 바로 시작은 정상 승격과 같은 기본 보너스(최대 체력 +20, 공격력 +6, 수익 50)를 적용합니다. 1장에서 획득한 종목·토템까지 복제하지는 않습니다.
- 직접 공격 약화는 전달된 공격자 객체에 적용하며 좌표가 같은 다른 적에게 전파되지 않습니다. 피해 로그에 source_id와 damage_kind를 추가했습니다. 적 투사체·보스 위험지대에는 생성 당시 공격자 ID를 보존합니다. 환경 경보는 source_id가 null이며 source_type은 environment입니다.
- 레버리지 상환은 실제 차감량을 health_cost / leverage_repayment로 기록합니다. 전투 피해 통계에는 포함하지 않습니다.
- 다음 검증: 브라우저에서 1·2장 입력·선택창·재시작 연속 점검, 실제 플레이 로그를 통한 기존 5종 밸런싱. 이번 안정화는 자동 테스트로 검증했으며 브라우저 플레이 완료를 의미하지 않습니다.

- 후속 안정화: 접촉·폭발·투사체·보스 바닥 공격의 출처 연결, 폭탄 자폭 처치 이벤트와 중복 방지. 자동 테스트 43개 통과. 브라우저 플레이 검증은 여전히 남아 있습니다.

## 여러 플레이 로그 분석

게임에서 내려받은 파일을 모아 실행합니다(Node.js 필요).

```sh
node scripts/analyze-runs.mjs session1.json session2.json > analysis.json
```

단일 도전 로그와 여러 도전이 담긴 runs 파일 모두 지원합니다. run_id + sequence로 중복을 제거하고 충돌한 이벤트는 오류로 표시합니다. 순서가 누락된 로그는 제외하며, 종료하지 않은 도전은 unresolved로 구분합니다. 토템 제시는 도전·방·토템마다 한 번만 세며 선택률 분모는 실제 제시 횟수입니다.

결과: 방별 시작·완료·사망·완료 전 종료·미종료 수, 완료율, 사망률, 완료한 방의 평균 시간, 토템별 제시·선택·발동 횟수와 형성 실패 사유. 상점은 kind=shop으로 분리합니다. 이는 수집한 도전들의 기술 통계이며 전체 사용자 이탈률이나 토템의 인과적 효과를 의미하지 않습니다.

개발 기록: 로그 병합·중복 제시·미종료·불완전 기록·충돌 검증을 추가해 전체 46개 테스트 통과. 다음 작업은 실제 내보낸 로그를 이 분석기에 적용하고 표본을 바탕으로 형성 시간과 보상을 조정하는 것입니다.

## 4장 중앙은행

국채 광장 → 긴축 회랑 → 최종 대부 창구 → 지급준비 금고 → 통화정책 위원회.
3장 출구에서 최대 체력 +20·공격력 +6·체력 45 회복·수익 50을 받고 진입합니다. 기존 종목과 토템은 유지됩니다. 1·2·4번 방에 탐험 상자·숨겨진 보관함·선택형 엘리트 도전을 연결했습니다.

중앙은행 총재: 금리 인상(순차 바닥 폭발), 유동성 공급(느린 부채꼴 탄막), 지급준비율 인상(중앙에 안전 구역을 남기는 바닥 공격). 공격 전 안내와 예고선을 제공하며 체력 절반 아래에서 회복 틈이 짧아집니다. 금융 개념을 게임용으로 각색한 패턴입니다.

4장 배경은 기관 배경에 황금색 필터를 적용합니다. 몹은 새 중앙은행 전용 스프라이트를 사용합니다. 전용 음악은 아직 없습니다. 기존 보상 풀과 상점이 연결됩니다. 개발 기록: 3→4장 전환·토템 유지·정책 3종·최종 승격·종료 로그 검증 포함 47개 테스트 통과.
