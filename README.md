# The Liquidation of Penny

금융 테마 2D 액션 로그라이트의 독립 실행 브라우저 데모입니다. 기존 Godot 프로젝트를 변경한 버전은 아닙니다.

## 플레이 범위

1장 잡주의 골목: 폐장 골목 → 손절 교차로 → 공칠의 거래소 → 폐쇄 거래소(엘리트) → 작전세력 소굴(보스) → 2장 진입.

2장 기관의 벽: 증권사 로비 → 기관 주문센터 → 리스크 관리실 → 공매도 구역(엘리트) → 헤지펀드 본사(보스) → Small Cap 상장 결과. 전반부 스테이지는 `Degraded Signal` BGM을 사용합니다. 실시간 금융 데이터, 결제, 가챠, 길드, PvP는 사용하지 않습니다.

## 조작

| 키 | 기능 |
|---|---|
| ← / → | 이동 |
| C | 점프, 공중에서 한 번 더 점프 |
| X | 3단 기본 공격, 길게 누르면 반복 |
| Z | 짧은 무적 대시 |
| A | 미실현 수익 25 이상 소모하여 익절 공격 |
| S | 8초 레버리지, 공격 피해 ×1.65 |
| D | 서킷브레이커, 적과 투사체 2초 정지 |

| 1 / 2 / 3 | 보상 선택 |
| Esc | 일시 정지 / 계속하기 |

터치 기기에는 이동·공격·점프·대시·상호작용 버튼을 제공합니다.

## 경제 규칙

- 시장은 게임 내부에서 횡보 → 상승 → 하락 순으로 24초마다 전환됩니다. 전환 4초 전에 예고합니다.
- 상승장 공격력 +15%. 하락장 적 피해 +15%, 시드 보상 +35%.
- 공격 적중 시 미실현 수익 +8, 최대 100. 피격 시 보유 수익의 25% 손실.
- 익절은 보유 수익 전부를 소모하여 전방 범위 공격. 수익이 높을수록 피해가 증가합니다.
- 레버리지: 8초 안에 2마리 처치 또는 총 피해 160 달성 시 시드 +18. 실패하면 체력 18 상환, 체력은 1 미만으로 내려가지 않습니다. 방 전환 시 남은 계약을 정산합니다.
- 전투방을 정리하면 8종 카드 중 3개를 제시하고 1개를 선택합니다. 한 판 안에서 중첩됩니다.
- 종료 시 투자 지식만 로컬 브라우저에 저장합니다. 지식 1당 다음 시작 체력 +2, 최대 +20. 진행 중인 한 판을 이어 하는 기능은 없습니다.

## 구조

- `engine.mjs`: 렌더링·DOM과 분리된 전투 및 경제 시뮬레이션.
- `game.js`: 입력, Canvas 렌더링, UI, Web Audio 효과음, 로컬 메타 성장 저장.
- 루트의 PNG·MP3 파일: 승인된 시안을 기반으로 제작한 래스터 에셋. 원본 PNG는 유지합니다. 게임 렌더링 표면에서 알파·마젠타·초기 시안의 중성 체크 배경을 처리하고 각 포즈의 영역과 표시 크기를 맞춥니다. 이 처리 결과를 독립 투명 PNG로 내보내는 기능은 없습니다.
- `tests/engine.test.mjs`: 충돌, 2단 점프 제한, 대시, 수익·상환, 방 전환, 상점, 보스 종료 등 회귀 테스트.

`node --test tests/engine.test.mjs`로 시뮬레이션 검증을 실행할 수 있습니다. 정적 파일 배포이므로 별도 설치/빌드가 필요하지 않습니다.

## 현재 한계

8포즈 기반의 초기 애니메이션입니다. 모션 사이의 중간 프레임, 별도 사망 애니메이션, 게임패드와 키 재설정, 3장 이후 콘텐츠는 후속 작업입니다. 게임 스케일과 발 위치는 렌더링 단계에서 맞추며, 완성형 저해상도 스프라이트의 픽셀 단위 수작업 정리는 아직 남아 있습니다.


## 차트 토템 — 첫 구현 5종

전체 분류는 추세 전환형 9종, 추세 지속형 3종, 중립형 2종, 특수형 2종입니다.
현재 이중 바닥·이중 천장·깃발형·삼각수렴·컵앤핸들을 구현했습니다. 나머지 11종은 분류만 등록되어 있습니다.
패턴 개념은 제공받은 Yonsei_dent 차트 패턴 가이드(2024-11-17)를 참고했으며, 전투 조건·수치는 게임용 설계입니다. 원문 및 도해는 게임에 복제하지 않았습니다.

- 1장 1·2·4번 방, 2장 1·2·4번 방의 마지막 발판에서 이어지는 2단 상층 경로에 차트 보관함이 있습니다. 미보유 토템 최대 2종 중 하나를 선택하며, 전부 보유했다면 시드 40을 얻습니다. 발판 위 작은 상자(24×18)에 닿으면 자동으로 차트 선택 화면이 열립니다.
- I 또는 상단 토템 버튼으로 수집품을 열고, 토템 선택 후 슬롯을 선택해 장착합니다. 최대 3종이며 메뉴에서는 전투가 정지합니다.
- 토템은 한 도전 동안 보유합니다. 사망·새 도전 시 초기화되며 장 전환 시에는 보유·장착을 유지합니다.
- 형성 제한은 8초입니다. 방 전환·장착 해제는 형성을 초기화합니다. 재장착으로 재사용 대기시간을 없앨 수 없습니다.
- 회피 조건은 대시 무적 중 피해 판정을 실제로 막았을 때 인정하고 대시 한 번당 최대 한 번 기록합니다.
- 토템 메뉴에 각 효과와 조건을 표시합니다. 보조 피해는 새 공격 이벤트를 만들지 않습니다.
- 메뉴에서 토템 이벤트를 JSON으로 내려받을 수 있습니다. 서버 전송 없이 현재 도전 메모리의 최근 5,000개만 제공하며, 전체 게임 분석 수집 기능은 아직 아닙니다.
- 신규 모듈: `totems.mjs`, `totem-ui.mjs`. 검증: `node --test tests/*.test.mjs`.

탐험 경로는 선택 사항으로 기존 바닥과 출구는 유지됩니다. 보상을 미루고 돌아올 수 있으며, 선택지를 다시 열어도 내용은 바뀌지 않습니다. 토템 제시 목록과 선택·보류를 함께 기록합니다.

## 개발 기준

이 프로젝트의 기준 저장소는 https://github.com/ryemso/The-Liquidation-of-Penny 입니다. 이후 변경은 이 저장소의 최신 상태를 먼저 확인하고 반영합니다. GitHub 버전은 루트에서 HTML·JS·PNG·MP3를 제공합니다. Sites 작업본의 `dist/` 파일은 루트에, `dist/assets/` 파일도 루트에 대응합니다. 두 저장소 간 자동 동기화 서비스는 설정되어 있지 않습니다.

로컬 실행: 저장소 루트에서 `python -m http.server 8000` 실행 후 브라우저로 `http://localhost:8000`에 접속합니다. 테스트는 `node --test tests/*.test.mjs`로 실행합니다.

보상 선택을 미루면 상자에서 벗어났다가 다시 닿을 때만 선택 화면이 열립니다. 맵의 큰 차트 표시는 작은 픽셀 상자로 교체했으며, 선택 메뉴의 차트 이미지는 유지합니다.
